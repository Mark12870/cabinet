# Where the Library's artwork came from

Every image in `data/library/<vendor>/`, and what it is.

Cabinet ships these so the Library works offline. Each `<vendor>/<id>.jpg` is the plugin's own
interface and each `<vendor>/<id>.png` a square crop of it, resized here; nothing was redrawn.
Neural DSP's icons are the exception: each product's white glyph, taken from its installer's own
icon, or the site icon named below, set on one common tile.

The Klevgrand Helper's `klevgrand-helper-runtime.zip` contains the MSYS2 MinGW libarchive 3.8.9-5
runtime and its pinned dependencies. Its package hashes, source links, relinking details and licence
notices are in `data/library/klevgrand/klevgrand-helper-runtime.txt`; the archive SHA-256 is
`50faa6b30310fbe8cd5807405153fcdf61a020321fb58428cc74a98bf2e39790`.
